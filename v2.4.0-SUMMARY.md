## Architecture Changes

### New Files Created
- `src/hooks/useComparison.ts` — Translation comparison state/logic
- `src/hooks/useSettings.ts` — Reader settings and theme helpers
- `src/hooks/useSync.ts` — Cloud sync (login, register, push, pull)
- `src/components/SyncPanel.tsx` — Sync UI (login/register/push/pull)
- `worker/sync.ts` — Sync API endpoints
- `worker/schema.sql` — D1 database schema

### Files Modified
- `src/App.tsx` — Reduced from 1123 to ~1050 lines, added sticky indicator
- `src/components/Sidebar.tsx` — Added sync panel, highlight filter, date display
- `src/components/HighlightToolbar.tsx` — Added underline style toggle
- `src/components/VerseLine.tsx` — Support for underline style
- `src/hooks/useStudyData.ts` — Added style parameter for highlights
- `src/types.ts` — Added HighlightStyle type
- `public/sw.js` — Optimized to pre-cache only WEB translation (v11)
- `worker/index.ts` — Added sync route handling
- `wrangler.jsonc` — Added D1 database binding
- `package.json` — Renamed to `bible-in-african-languages`
